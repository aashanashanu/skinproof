## Before a Demo or Submission

Use simulated examples only as visibly labeled illustrations. Exercise the hosted camera flow on the target device, confirm the API is healthy, and distinguish uploaded sample runs from a verified live camera capture. The public hackathon submission also needs its own project description, screenshots, repository access, and demo-video link.
